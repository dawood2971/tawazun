# تَوازُن

تطبيق شخصي بالعربي: المهام والصلاة (مَسَار)، العادات والصحة (واحة)، البيت والراشن والفواتير (بيتي)، والراتب والحصالة والمصاريف (غوازي).

- يشتغل بدون إنترنت بعد أول فتحة.
- البيانات محفوظة في المتصفح على الجهاز فقط، وما تنرفع لأي مكان.
- للتثبيت على الجوال: افتح الصفحة، ثم «إضافة إلى الشاشة الرئيسية».
